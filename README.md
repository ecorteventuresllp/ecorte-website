# Ecorte Ventures LLP website

Static website ready for GitHub Pages. No build step is required.

1. Create a GitHub repository and upload this folder.
2. In **Settings → Pages**, select **Deploy from a branch**, then `main` and `/ (root)`.
3. Add `ecorte.in` as the custom domain in GitHub Pages and enable HTTPS when available.
4. In GoDaddy DNS, enter the records GitHub Pages displays in its custom-domain setup.

Before publishing, change `info@ecorte.in` if your preferred business inbox differs.
